# DeepNoise Showcase

Public-facing personal showcase page for **DeepNoise Flow**.

## Open locally

Serve the demo directory:

```bash
python -m http.server 8080 --directory demo
```

Then open `http://127.0.0.1:8080` in your browser.

If you prefer a direct file-open command:

- macOS: `open demo/index.html`
- Linux: `xdg-open demo/index.html`
- Windows (PowerShell): `start demo/index.html`

## What it contains

- Project overview and workflow explanation
- Interactive demo capabilities summary (upload, record, preview, download)
- Safety guardrails for public traffic (size/duration/rate/timeout)
- Quick start commands for local API + UI
